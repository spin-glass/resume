# Portfolio: Resume Review Agent System

This project is a **production-grade multi-agent AI system** built to automatically review and improve resumes. It demonstrates advanced engineering practices in agent orchestration, cost optimization, and scalable LLM integration.

## Project Overview

The Resume Review System uses **LangGraph** (by LangChain) to coordinate five specialized AI agents that evaluate resumes from different perspectives: recruiting, technical depth, marketing effectiveness, UX, and visual design. The system achieves significant cost and performance improvements through a **hybrid multi-model architecture**.

**Key Achievement**: **50% cost reduction** and **70% faster execution** compared to single-model (Claude-only) baseline.

---

## Technical Highlights

### 🏗️ Architecture & Design

- **LangGraph StateGraph**: Complex DAG workflow with fan-out/fan-in pattern for parallel agent execution
- **Type-Safe State Management**: Pydantic 2.0 models with runtime validation
- **Stateless Agent Nodes**: Pure functions enabling easy testing and debugging
- **Graceful Degradation**: Optional features (design review) don't block core workflow

### 🧠 Multi-Agent Orchestration

Five specialized agents running in parallel:

| Agent | LLM Model | Expertise | Weight |
|-------|-----------|-----------|--------|
| **Recruiter** | Gemini 3.0 Flash | Contract acquisition perspective | 30% |
| **Technical Writer** | OpenAI o3-mini | Technical depth & clarity | 20% |
| **Copywriter** | Claude Sonnet 4.5 | Marketing effectiveness | 25% |
| **UX Designer** | Gemini 3.0 Flash | Information hierarchy | 15% |
| **Visual Designer** | Gemini 3.0 Flash | Visual presentation | 10% |

### 💰 Cost Optimization

**Multi-Model Hybrid Strategy**:
- Different LLM providers for different cognitive tasks
- Cost-effective models (Gemini Flash) for high-volume evaluation
- Premium models (o3-mini, Claude Sonnet) for specialized reasoning
- **Result**: $0.50/review vs $1.10 baseline (55% savings)

### 🔧 Advanced Tool Integration

- **Playwright**: Headless browser for screenshot capture
- **Quarto**: Document validation with auto-retry loop
- **Multi-Model LLM Client**: Unified interface across Gemini, OpenAI, Anthropic
- **Structured Output**: Pydantic models for type-safe agent responses

**Fan-out/Fan-in Pattern**:
- Router triggers parallel execution of 3 agents
- Aggregator waits for all completions and merges results
- **3x speedup** from parallelization

## Key Design Decisions

### Why LangGraph?

**Chosen over** LangChain LLMChain, custom orchestration

✅ Native support for complex DAGs (fan-out/fan-in)  
✅ Built-in state management with automatic synchronization  
✅ Visual debugging via LangSmith traces  
✅ LangGraph Studio for interactive development

### Why Pydantic for State?

**Chosen over** plain dictionaries, dataclasses

✅ Runtime validation of state transitions  
✅ Type safety with mypy (100% type coverage)  
✅ Automatic JSON serialization  
✅ Clear contract for node inputs/outputs

### Why Multi-Model Hybrid?

**Chosen over** Claude-only, Gemini-only

✅ **Cost optimization**: 50% savings using cheaper models for evaluation  
✅ **Performance**: 70% faster with lightweight models  
✅ **Best-of-breed**: o3-mini reasoning, Claude creativity, Gemini efficiency  
✅ **Resilience**: Fallback options if one provider has issues
