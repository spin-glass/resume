# Data Model: Quarto Validation Auto-Retry Loop

**Phase**: 1 (Design & Contracts)
**Date**: 2026-01-09
**Branch**: 009-quarto-retry-loop

## Overview

This feature introduces new data entities to track validation results and retry attempts. These entities integrate with the existing Feedback and Issue models to enable automatic retry loops.

## Entities

### ValidationResult

**Purpose**: Represents the outcome of a single Quarto validation attempt

**Source**: Spec entity "ValidationResult" (line 103)

**Fields**:

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `is_valid` | `bool` | Yes | - | True if Quarto validation passed |
| `error_message` | `str \| None` | No | `None` | Error details from Quarto stderr/stdout |
| `timestamp` | `datetime` | Yes | `datetime.now()` | When validation was performed |
| `attempt_number` | `int` | Yes | - | Which retry attempt this was (0 = initial, 1+ = retries) |

**Validation Rules**:
- `error_message` MUST be non-empty when `is_valid=False`
- `error_message` SHOULD be `None` when `is_valid=True`
- `attempt_number` MUST be >= 0

**Relationships**:
- Created by: `QuartoValidator.validate()`
- Consumed by: `ReviewWorkflow._validate_and_retry()`
- Logged by: `RetryLogger.log_attempt()`

**Example**:
```python
ValidationResult(
    is_valid=False,
    error_message="ERROR: Invalid markdown: Unexpected '#' at line 34",
    timestamp=datetime(2026, 1, 9, 18, 15, 23),
    attempt_number=0
)
```

### ValidationFeedback

**Purpose**: Structured feedback generated from Quarto validation errors, used to guide revisor corrections

**Source**: Spec entity "ValidationFeedback" (line 104)

**Note**: This is a specialized use case of the existing `Feedback` model (from models/feedback.py), not a new model. We'll construct Feedback instances with specific characteristics for validation errors.

**Construction Pattern**:

| Field | Value for Validation Feedback |
|-------|-------------------------------|
| `agent_name` | `"quarto_validator"` |
| `score` | `3.0` (low score to trigger revision) |
| `strengths` | `[]` (no strengths when validation fails) |
| `issues` | List of `Issue` objects parsed from error message |
| `suggestions` | `["Quarto構文エラーを修正してください"]` |

**Issue Generation**:
- Parse Quarto error message using pattern matching (see Error Patterns below)
- Each pattern maps to an Issue with specific `description`, `severity`, `action_type`
- If no pattern matches, create generic Issue with raw error message

**Relationships**:
- Generated by: `QuartoValidator._create_validation_feedback()`
- Consumed by: Revisor node (via state.current_feedback)
- Distinguishing feature: `agent_name="quarto_validator"` allows revisor to recognize validation vs. agent feedback

### RetryAttempt

**Purpose**: Record of a single retry iteration within a validation retry loop

**Source**: Spec entity "RetryAttempt" (line 105)

**Fields**:

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `attempt_number` | `int` | Yes | - | Sequential retry number (1, 2, 3...) |
| `timestamp` | `datetime` | Yes | `datetime.now()` | When retry attempt started |
| `error_detected` | `str` | Yes | - | Error message that triggered this retry |
| `correction_applied` | `str` | Yes | - | Summary of Issues from validation feedback |
| `validation_result` | `ValidationResult` | Yes | - | Outcome of validation after correction |
| `qmd_snapshot_path` | `Path \| None` | No | `None` | Path to saved retry QMD file |

**Validation Rules**:
- `attempt_number` MUST be > 0 (initial attempt is not a retry)
- `error_detected` MUST be non-empty
- `correction_applied` should summarize the Issues that were addressed

**Relationships**:
- Created by: `ReviewWorkflow._validate_and_retry()`
- Consumed by: `RetryLogger.log_attempt()`
- Persisted to: Retry log markdown file

**Example**:
```python
RetryAttempt(
    attempt_number=1,
    timestamp=datetime(2026, 1, 9, 18, 15, 45),
    error_detected="Invalid markdown: Unexpected '#' at line 34",
    correction_applied="Removed standalone # markers via _auto_fix_structure()",
    validation_result=ValidationResult(is_valid=True, ...),
    qmd_snapshot_path=Path("session_20260109/iter2_retry1.qmd")
)
```

### RetryLog

**Purpose**: Aggregated log of all retry attempts for a single resume iteration

**Source**: Spec entity "RetryLog" (line 106)

**Note**: This is a file-based entity (markdown log), not a Python model. The structure is defined by the markdown format.

**File Format**:

```markdown
# Iteration {iteration_number} - Validation Retry Log

## Initial Validation ({PASSED|FAILED})
- Timestamp: {ISO 8601 datetime}
- Error: {error_message or "None"}
- Action: {Next action}

## Retry {attempt_number}
- Timestamp: {ISO 8601 datetime}
- Fix Applied: {correction summary}
- Validation Result: {PASSED|FAILED}
- Error: {error_message if failed}
- Action: {Next action}

[... additional retry sections ...]

## Summary
- Total Retries: {count}
- Final Status: {SUCCESS|FAILED}
- Final File: {qmd_file_path}
```

**File Location**: `{session_dir}/iter{N}_validation_retry.md`

**Relationships**:
- Generated by: `RetryLogger.write_log()`
- Contains: All RetryAttempt records for one iteration
- Read by: Users for debugging

## Error Pattern Mapping

This table defines how Quarto error messages map to Issue objects in ValidationFeedback.

| Pattern Name | Quarto Message Contains | Issue.description | Issue.severity | Issue.action_type | Issue.location |
|--------------|-------------------------|-------------------|----------------|-------------------|----------------|
| Standalone marker | "invalid heading", "unexpected #" | "単独の # 記号が検出されました。セクション区切りとして不適切です。" | `CRITICAL` | `REMOVE` | `None` (global) |
| YAML syntax error | "yaml", "frontmatter" | "YAMLフロントマターに構文エラーがあります。" | `CRITICAL` | `RESTRUCTURE` | "## YAML Header" |
| Unclosed code block | "code block", "```" | "コードブロックが正しく閉じられていません。" | `HIGH` | `RESTRUCTURE` | `None` |
| Invalid table | "table", "column" | "Markdownテーブルの列数が不一致です。" | `HIGH` | `REMOVE` | `None` |
| Unknown error | (no match) | "Quarto検証エラー: {raw_error_message}" | `HIGH` | `RESTRUCTURE` | `None` |

**Implementation**: These patterns are defined as constants in `quarto_validator.py` and used by `_create_validation_feedback()`.

## State Extensions

The existing `ReviewState` (workflow/state.py) will be extended with retry-related fields:

**New State Fields**:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `validation_retry_count` | `int` | `0` | Current retry count for this iteration |
| `max_validation_retries` | `int` | `3` | Maximum allowed retries (from config) |
| `strict_validation` | `bool` | `False` | Exit on validation failure (from config) |
| `current_retry_attempts` | `list[RetryAttempt]` | `[]` | Retry history for current iteration |

**State Reducers**:
- `validation_retry_count`: Simple assignment (no reducer needed)
- `current_retry_attempts`: Append to list (similar to `add_feedback` reducer)

**Reset Logic**:
- Reset `validation_retry_count` and `current_retry_attempts` to defaults when incrementing `current_iteration`

## File Artifacts

### Retry QMD Snapshots

**File Pattern**: `{session_dir}/iter{iteration}_retry{attempt}.qmd`

**Purpose**: Preserve intermediate QMD files after each retry attempt for debugging

**Lifecycle**:
1. Created by: `ReviewWorkflow._save_retry_artifact()`
2. Referenced in: RetryAttempt.qmd_snapshot_path
3. Preserved for: Duration of session (not automatically cleaned up)

**Example Paths**:
- `session_20260109_181500/iter2_retry1.qmd` (first retry of iteration 2)
- `session_20260109_181500/iter2_retry2.qmd` (second retry of iteration 2)
- `session_20260109_181500/iter2_retry3.qmd` (third retry of iteration 2)

### Retry Log Files

**File Pattern**: `{session_dir}/iter{iteration}_validation_retry.md`

**Purpose**: Human-readable log of all validation attempts for one iteration

**Lifecycle**:
1. Created by: `RetryLogger.create_log()`
2. Appended by: `RetryLogger.log_attempt()` after each retry
3. Finalized by: `RetryLogger.finalize_log()` when retry loop completes

**Example Path**:
- `session_20260109_181500/iter2_validation_retry.md`
