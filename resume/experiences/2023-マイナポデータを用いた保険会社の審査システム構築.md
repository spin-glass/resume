# Situation
株式会社JMDCにて、保険会社の引受審査業務のデジタル化・高度化を目的としたプロジェクトに参画しました。
従来、保険の加入審査は書面ベースの告知や診断書に基づいて行われていましたが、マイナポータル（政府運営のオンラインサービス）から取得できる医療情報や特定健診情報を活用することで、審査の迅速化と精度向上を目指すこととなりました。
プロジェクトは12名規模のチームで構成され、データエンジニアリングとシステム開発の統合が求められる環境でした。

# Task
私は要件定義・設計・開発のフェーズを担当しました。主なミッションと技術的課題は以下の通りです。
- **マイナポータルデータの正規化**: 複雑な構造を持つ医療情報（XML/JSON形式等）を、保険会社の審査ロジックで利用可能な形式に変換するデータパイプラインの構築。
- **高セキュリティな基盤設計**: 極めて機密性の高い個人情報（健康・医療データ）を扱うため、AWS上での厳格なセキュリティ要件（暗号化、アクセス制御）の充足。
- **審査ロジックの実装**: 医師や審査担当者の知見をアルゴリズム化し、自動審査を支援するバックエンド機能の開発。

# Action
技術面では、AWSのサーバーレスアーキテクチャを中心とした堅牢なシステムを構築しました。
- **データ連携基盤の開発**: 
    - マイナポータルから連携される医療情報を、AWS LambdaおよびAWS Glueを用いてETL処理し、審査に必要な項目を抽出・構造化するパイプラインを実装しました。
- **セキュリティの徹底**: 
    - AWS KMSを用いたデータのエンベロープ暗号化、およびIAMロールによる厳格な権限管理を徹底しました。[要確認]
    - データの入出力ログをCloudWatch LogsおよびAWS CloudTrailで詳細に記録し、監査可能な状態を構築しました。
- **スケーラビリティの確保**: 
    - 大量の審査リクエストを並列処理するため、AWS Step Functionsを用いてワークフローを管理し、処理の再試行制御やエラーハンドリングを自動化しました。
- **IaCによる管理**: 
    - Terraformを用いてインフラをコード化し、開発・検証・本番環境の構成差異を排除し、デプロイの安全性と再現性を確保しました。[要確認]

# Result
- **審査業務の効率化**: 従来、数日〜数週間を要していた医療情報の確認・照合作業を自動化し、審査回答までのリードタイムを大幅に短縮する基盤を構築しました。
- **審査精度の向上**: 公的な医療データに基づく客観的な審査が可能となり、手入力によるミスや申告漏れのリスクを低減しました。
- **コンプライアンスの遵守**: 金融機関・医療データを扱う厳格なセキュリティ基準をクリアし、安全なデータ活用モデルを実証しました。
