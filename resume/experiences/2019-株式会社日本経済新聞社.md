# Situation
日本最大級の経済メディアである「日本経済新聞」のデジタル版において、数百万人のユーザーに対し、膨大なニュース記事から最適な情報を届けるパーソナライズ機能の高度化が求められていました。当時はデータ分析基盤の統合や、モデル構築から本番デプロイまでのリードタイム短縮が課題となっていました。

- **チーム規模**: 約5〜10名（[要確認]：データサイエンティスト、データエンジニア、バックエンドエンジニア混成チームを想定）
- **ミッション**: ニュースアプリにおけるユーザーエンゲージメント（CTR等）の向上と、持続可能なMLOps基盤の構築

# Task
データ基盤エンジニア兼データサイエンティストとして、以下の2点を主軸に担当しました。
1. **MLOps基盤の設計・構築**: 散在していたデータ処理プロセスを統合し、実験からデプロイまでをシームレスに行える環境の整備。
2. **推薦アルゴリズムの高度化**: 従来のロジックを超え、深層学習（BERT）や大規模データ処理（Spark）を駆使した高精度なレコメンデーションエンジンの開発。

# Action
技術選定から実装まで、以下のプロセスを主導しました。

- **Databricksを中心としたMLOps基盤の導入**:
    - データ基盤選定から実装までを単独で主導。AWSおよびGCP環境下でDatabricksを導入し、Spark（PySpark/Scala）を用いた数百万ユーザー規模のログデータの一元管理と分散処理を実現。
    - MLflowを活用し、実験管理、モデルのバージョン管理、デプロイフローを自動化。これにより、モデルのライフサイクル管理の効率を大幅に向上させました。
- **ハイブリッドな推薦エンジンの開発**:
    - **協調フィルタリング**: ユーザーの閲覧履歴に基づき、類似した嗜好を持つユーザーが読んでいる記事を抽出。
    - **BERT（NLP）の活用 - 自社データによる事前学習**: 経済ニュース特有の文脈を捉えるため、自社記事データを用いたBERTの事前学習（Pre-training from scratch）を実施。数百万件規模のドメイン特化データを処理してゼロからモデルを構築・評価し、記事のセマンティック情報を推薦システムに組み込みました。
- **データパイプラインの最適化**:
    - Golangを用いた高パフォーマンスなデータ処理コンポーネントの実装や、Scala/SparkによるETL処理の最適化を行い、膨大なトラフィックに耐えうる基盤を構築しました。

# Result
- **ビジネスインパクト**: 推薦アルゴリズムの刷新により、ニュースアプリ内における記事のクリック率（CTR）を大幅に改善。
- **開発効率の向上**: MLOps基盤の確立により、従来は手動プロセスの多かったモデルの検証から本番環境へのデプロイまでの期間を劇的に短縮しました。
- **技術的負債の解消**: スケーラブルなSpark基盤への移行により、将来的なデータ量増加にも柔軟に対応可能なアーキテクチャを実現しました。
