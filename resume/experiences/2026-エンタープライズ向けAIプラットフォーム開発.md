# Situation
AIエージェント、リアルタイム文字起こし、およびCRM連携（Salesforce/Kintone/Zoho/Mach等）を統合した、エンタープライズ向けSaaSプラットフォームの開発プロジェクトです。約20名体制で、20以上のアプリケーション・ライブラリをNx monorepoで管理しており、Python製エージェントサービスとMCPサーバー群を含む3リポジトリ構成で開発が進められていました。主要顧客企業のCRMシステム（Mach）との連携が急務となっていました。

# Task
フリーランスのフルスタックエンジニアとして、以下を担当しました。
1. **新規CRMコネクタの0→1構築（Mach CRM）**: 認証基盤からMCPサーバー、Kubernetes設定、APIキー認証ミドルウェアまで、3リポジトリ横断で全フェーズを単独担当
2. **CRMベクトル検索のMCPサーバー化（Zoho CRM）**: Native ToolからMCPサーバーへのアーキテクチャ移行を設計・実行
3. **既存CRMコネクタの不具合修正（Salesforce）**: 自動転記の商談紐付けロジック改善
4. **営業支援UIの改善**: カレンダー操作、レポート生成、入力バリデーション等のフロントエンド機能開発（7本のPR）

# Action
- **Mach CRM コネクタの0→1構築**:
  NestJS側ではCookie認証・自動再認証・リトライ機構の構築、`pageConfig`パターンによるフィールドマッピング、フィーチャーフラグによる組織単位のアクセス制御、`CollectionsController`への6エンドポイント追加を5フェーズで実施。既存の共有コード（ガード・コントローラー・インターフェース）を一切変更しない設計を貫いた。APIキー認証ミドルウェアでは`x-api-key`を既存認証ヘッダー群に変換するパターンを採用し、BFF側で`ApplicationApiKey`を自動発行することでユーザーにAPIキー発行を意識させないUXを実現。Python/FastMCPでmcp-server-machを新規構築（6ツール・28テスト）し、Terraform・Kubernetesの設定をstaging/production両環境に追加した。

- **Zoho CRM ベクトル検索のMCPサーバー移行**:
  agent_service内にNative Toolとして実装・検証（1,826行・60テスト）した後、mcp-server-zoho-crmとしてjai-toolsへ切り出し、agent_serviceからNative実装を完全削除（1,316行削除）。NestJS側にもベクトル検索エンドポイントを追加し、`userId`スコープでのマルチテナントデータ分離を実装した。

- **agent_serviceのMCPインフラ拡張**:
  MCP tool DBの`env_vars`フィールドを`DefaultMcpLoader → JaiClusterUrlResolver → mcp-api`に貫通させ、`configMapEnvs`としてKubernetesコンテナに環境変数を注入可能にした。後続のMCPサーバー追加時の設定コストを削減する基盤を整備した。

- **Salesforce 自動転記の精度改善**:
  WhatId（商談ID）欠落バグを修正。ロジックを`SalesforceTransformer`に閉じ込め、共有サービスへのプロバイダー固有ロジック混入を回避した。

- **営業支援UIの改善**:
  iPhone SE3対応のカレンダーレスポンシブ対応、ドラッグ操作のoptimistic updates、Salesforceフィールド定義を参照したLLMハルシネーション防止ガードレール、`pageConfig`経由の条件付き必須バリデーション、Recall AIメタデータを活用した会議コンテキストのエージェント注入等を実装した。

# Result
- **Mach CRM連携の本番稼働**: 3リポジトリ・5フェーズにわたる実装を既存共有コード変更ゼロ・他コネクタへの回帰影響ゼロで本番リリース
- **MCPサーバー2基の新規構築**: mcp-server-mach（6ツール）・mcp-server-zoho-crm（2ツール）をKubernetes上でオンデマンド起動する運用体制を確立
- **Native Tool → MCP移行パターンの実証**: Zoho CRMツールで実装→検証→切り出しの移行パターンを実行し、後続ツール移行の前例を作った
- **MCPインフラの拡張性向上**: `env_vars`パイプライン整備により、後続MCPサーバー追加時の設定をDB操作のみで完結可能にした
- **営業担当者のモバイル操作性向上**: レスポンシブ対応・カレンダー編集・LLMハルシネーション防止等により、外出先での利用体験を改善
