# Situation
HJホールディングス株式会社が運営するVODサービスにおいて、TVOD（都度課金型ビデオ・オン・デマンド）作品の視聴促進を目的とした推薦システムの構築プロジェクトです。
ユーザーの嗜好に合わせたパーソナライズ、および関連性の高いアイテム推薦を実現することで、購入率（コンバージョン）の向上とユーザー体験の改善が求められていました。
チーム体制は6名で、唯一の機械学習エンジニアとして、技術選定からビジネスサイドとのKPI調整、推薦ロジックの設計、プロダクション環境へのデプロイ、効果検証までを一貫してリードしました。

# Task
本プロジェクトにおける主なミッションは、以下の技術的課題を解決することでした。
1. **推薦精度の高度化**: 従来のアルゴリズムでは捉えきれなかったアイテム間の潜在的な類似性や、ユーザーの文脈（セッション内の行動）を反映した推薦。
2. **コールドスタート問題の解消**: 新規作品や視聴履歴の少ないユーザーに対する推薦精度の維持。
3. **MLOps基盤の確立**: モデルの学習・推論・評価を安定的に運用するための自動化パイプラインの構築。
4. **定性的な妥当性の確保**: ジャンル間の自然な遷移など、ユーザーが違和感を感じない推薦結果の提供。

# Action
課題解決のため、以下の技術的アプローチを主導・実施しました。

- **ビジネス・リーダーシップとKPI設計**:
  データ希薄性の高いTVOD（都度課金）領域において、単なるCVR（購入率）だけでなく、「詳細ページ遷移率」を中間KPIとして設定しビジネスサイドと合意形成。A/Bテストを通じてCTRおよび視聴時間の向上を実現しました。

- **Two-Tower / DeepFM / Hybrid Architectureの構築**:
  Google推奨のTwo-Tower Architectureをベースに、Factorization Machine (LightFM) の概念を統合したハイブリッドモデルを構築。LightFMで生成したユーザー・アイテムの潜在特徴量（Latent Factors）をTwo-Towerモデルの入力として統合し、FMの相互作用とDeepの汎化性能を組み合わせた高精度な推薦を実現しました。

- **EmbeddingとContextを統合したDNN Ranking Model**:
  Rankingフェーズにおいては、TFRS（TensorFlow Recommenders）を用いて、Embeddingだけでなくコンテキスト情報を結合（Concatenate）したDeep Ranking Modelを構築。Wide & Deepと同様にスパースな特徴量と密なベクトルを統合してCTR予測を行い、推論レイテンシと精度の両立を実現しました。

- **メトリックラーニング（Triplet Loss）の導入**:
  PyTorch Similarityを用い、同一セッション内での連続視聴パターンからポジティブペアを抽出。Lift値を教師ラベルとして活用することで、関連性の高いアイテムがベクトル空間上で近くなるよう最適化しました。

- **Vertex AI Pipelinesを用いた完全自動化MLOps**:
  Vertex AI PipelinesやDatabricks/MLflowを活用し、学習・推論・評価のパイプライン自動化、およびドリフト検知等のモニタリング環境を構築。運用負荷を削減しつつ迅速なモデル改善サイクルを回す基盤を確立しました。

# Result
- **精度の向上**: アイテム埋め込みの評価指標（Accuracy）において、**0.91から0.96への改善**を達成しました。
- **定性的な改善**: UMAPによる分析の結果、ジャンル間の類似性が適切に学習され、ユーザーにとって違和感のない「自然な関連作品」の提示が可能となりました。
- **運用負荷の軽減**: Vertex AI PipelinesとDigdagによる定期実行ジョブの構築により、モデルの再学習および推論結果のデプロイを自動化し、手動運用の工数を大幅に削減しました。
- **ビジネスインパクト**: A/Bテストを通じて、従来の推薦手法と比較してCTRおよび視聴時間の向上を確認しました（※具体的な向上率は[要確認]）。```
